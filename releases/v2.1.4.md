# 知乎提问助手 v2.1.4 · 自由拖动与网站免打扰

纯 Chrome 扩展，使用自己的 OpenAI 兼容 API Key 或知乎直答，把网页转为可编辑的知乎提问草稿。无需本地服务、Codex CLI、伴侣程序或常驻终端；macOS、Windows、Linux 使用同一份 ZIP。

## 本次更新

- **自由拖动**：「问」按钮可以拖动；提问助手与知乎草稿面板通过顶部标题栏拖动，自动限制在屏幕内，拖动不会误触点击。
- **网站过滤**：Dashboard 和扩展弹窗底部新增排除列表，每行一个域名或网址，自动包含子域名，保存后对已打开页面立即生效，清空即可恢复。
- **停止自动操作**：关闭草稿或将知乎排除时，中止尚未完成的填写与话题绑定，不删除知乎编辑器里已有的内容。
- **说明更新**：更新 README、安装升级指引，以及仓库和扩展描述。

## 下载与升级

下载附件 `ZhihuQuestionAssistant-Extension-2.1.4.zip` 并解压。**Chrome 加载的是具体文件夹，下载新 ZIP 不会自动更新已安装版本。**

1. 将新包替换到原加载的目录，或在 `chrome://extensions` 的开发者模式中「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的新目录。
2. 重新加载扩展，确认显示 **2.1.4**。
3. 刷新原来打开的网页，新拖动和过滤功能才会加载。

无需先卸载；本机保存的配置可以继续使用。仅会话保存的密钥可能需要重新填写。不要下载历史版本的 macOS / Windows 伴侣程序。

## 验证与注意事项

- 55 项自动测试、语法检查和差异检查通过，浏览器预览验证了拖动、即时隐藏/恢复及草稿关闭。
- 没有调用付费模型或发布真实知乎问题；真实知乎页面兼容性仍取决于网页结构。
- 拖动位置仅保留在当前页面，刷新恢复默认。网站过滤不撤销已经发出的模型请求。
- OpenRouter Base URL 请填写 `https://openrouter.ai/api/v1`，不要填写完整 `/chat/completions` 路径。
- 旧选区残留、多设置窗口并发保存覆盖仍为已知待修问题，详见仓库 [CODE_REVIEW.md](https://github.com/BretDeng/zhihu-question-assistant/blob/main/CODE_REVIEW.md)。
