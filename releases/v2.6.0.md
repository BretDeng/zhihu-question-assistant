## 在新手教程内完成首次配置

新手教程现在是五步操作流程：了解用途 → 连接模型 → 生成偏好 → 示例验证 → 开始使用。

- 在教程内新增或修改模型、填写密钥、保存并启用，不再跳转到 Dashboard。
- 直接选择提问风格、创建自定义风格、设置概括或网页原文以及图片开关。
- 与 Dashboard 共用模型和偏好，已有配置可继续使用。
- 点击「试生成」才会调用已保存的模型并消耗供应商额度；可预览一个结果，也可以跳过。
- 明确区分「已保存」和「已验证可用」，错误就地显示。

获取密钥仍需打开供应商网站。100 项测试和语法检查通过，浏览器预览使用虚构密钥与模拟模型验证流程，未进行真实付费调用。

升级后在 `chrome://extensions` 重新加载扩展，确认版本 **2.6.0**。从扩展面板点击「新手教程」即可体验新流程。
