# 知乎提问助手 v2.2.1 · 微信公众号正文

纯 Chrome 扩展，使用自己的 OpenAI 兼容 API Key 或知乎直答，将网页转为可编辑的知乎提问草稿。macOS、Windows、Linux 使用同一份 ZIP，无需本地服务或伴侣程序。

## 本次更新

### 修复

- **微信公众号正文**：公众号文章页的 `<body>` 带有 `comment_feature` 等站点功能类名。提取正文时会沿父元素向上检查，整页因此被当成评论区丢弃，再长的文章也会提示「当前页面正文较少，可以先选中一段文字再分析。」现在不再把页面外壳的类名当作噪声区域，并直接把 `#js_content` / `.rich_media_content` 识别为正文。页面内部的评论区和侧栏仍然排除。

完整列表见 [CHANGELOG.md](https://github.com/BretDeng/zhihu-question-assistant/blob/main/CHANGELOG.md)。

## 下载与升级

下载附件 `ZhihuQuestionAssistant-Extension-2.2.1.zip` 并解压。**下载 ZIP 不会自动更新 Chrome 中已安装的版本。**

1. 替换原来加载的扩展目录，或在 `chrome://extensions` 开启开发者模式后加载新的解压目录（直接包含 `manifest.json`）。
2. 重新加载扩展，确认版本为 **2.2.1**。
3. 刷新已打开的网页。

无需先卸载，原本本机保存的配置可继续使用；仅会话保存的密钥可能需要重新填写。

## 验证与边界

- 76 项自动测试与语法检查通过；已在真实公众号文章页验证能提取正文。
- 未调用付费模型或发布真实知乎问题。自动填写仍取决于知乎网页结构，最终发布由用户审核并点击。
