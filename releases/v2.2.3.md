# v2.2.3 · 逻辑合并与运行优化

统一后台草稿和知乎编辑器的正文截取与引用处理，减少网页中的重复工作，保留 v2.2.2 的教程、联动拖动、模型配置和网站过滤功能。

- 原文模式一批草稿只截取一次；超长正文取前部内容后继续生成。
- 来源链接跨截取边界时仍保留完整引用，过长网址不会突破 3000 字预算。
- 合并连续 DOM 变动的编辑器检查，减少重复布局读取与相同样式写入。
- 普通网页不再加载闲置拖动脚本，共用知乎 DOM 辅助函数并删除未使用回调。
- 补齐共享脚本的预览和打包依赖，语法检查自动覆盖全部扩展脚本。

验证：83 项自动测试与脚本语法检查通过。没有调用付费模型或提交真实知乎问题；模型服务的等待时间不受这次本地优化保证。

下载 ZIP 后解压，在 Chrome 的 `chrome://extensions` 中开启开发者模式并加载已解压扩展。升级请替换原加载目录或加载新目录，确认版本为 **2.2.3**，再刷新原网页。下载 ZIP 不会自动更新 Chrome 中的旧版。
