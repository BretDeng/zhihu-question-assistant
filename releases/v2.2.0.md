# 知乎提问助手 v2.2.0 · 新手教程与稳定性

纯 Chrome 扩展，使用自己的 OpenAI 兼容 API Key 或知乎直答，将网页转为可编辑的知乎提问草稿。macOS、Windows、Linux 使用同一份 ZIP，无需本地服务或伴侣程序。

## 本次更新

### 新增

- **新手教程**：首次安装自动打开教程页，实时显示模型配置、密钥和描述形式的准备情况，并附五步上手说明与知乎直答 Access Secret 获取步骤（[知乎数据开放平台](https://developer.zhihu.com/) → 登录 → [个人中心](https://developer.zhihu.com/profile) 创建密钥）。
- **网页面板引导**：首次打开「问」面板显示「三步上手」；未配置模型时按钮高亮「未配置模型 · 点此添加」，会话密钥失效时提示「需补充密钥」。
- **常见问题与报错**：Dashboard 内置 35 条排查指南。把报错原文粘贴到搜索框，即可找到对应原因和解决办法。
- **记住「问」按钮位置**：拖动后所有网站共用该位置，可一键恢复默认；面板支持 Esc 收起。

### 修复

- **模型输出容错**：单个草稿缺字段或话题数量不对时跳过该草稿，不再整批失败；兼容推理模型的 `<think>` 思考过程和 JSON 前后的说明文字。
- **完整端点地址**：误填 `…/v1/chat/completions` 时自动规范化，不再导致 404。
- **报错更具体**：新增 400 / 404 说明，并附上服务商返回的错误原文（自动遮蔽疑似密钥）。
- **历史选区**：记住的选中文本绑定当前网址，取消选择后清除，切换文章不再沿用旧选区。
- **多窗口并发保存**：扩展弹窗和 Dashboard 同时保存、切换或删除模型配置不再互相覆盖。
- 多段选区不再重复发送给模型；生成途中切换描述形式时分别显示当前草稿与下次分析的形式；扩展重新加载后提示刷新网页。

### 优化与安全

- 网页提问面板改用 closed Shadow DOM，网页脚本无法读取草稿和错误信息。
- 减少知乎长页面上查找提问入口和检测发布状态的开销。

完整列表见 [CHANGELOG.md](https://github.com/BretDeng/zhihu-question-assistant/blob/main/CHANGELOG.md)。

## 下载与升级

下载附件 `ZhihuQuestionAssistant-Extension-2.2.0.zip` 并解压。**下载 ZIP 不会自动更新 Chrome 中已安装的版本。**

1. 替换原来加载的扩展目录，或在 `chrome://extensions` 开启开发者模式后加载新的解压目录（直接包含 `manifest.json`）。
2. 重新加载扩展，确认版本为 **2.2.0**。
3. 刷新已打开的网页。

无需先卸载，原本本机保存的配置可继续使用；仅会话保存的密钥可能需要重新填写。从旧版升级不会自动弹出教程，可在扩展弹窗点「新手教程」打开。

## 验证与边界

- 75 项自动测试与语法检查通过；教程页与常见问题搜索已做浏览器预览验证。
