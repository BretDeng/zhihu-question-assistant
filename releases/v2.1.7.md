# 知乎提问助手 v2.1.7 · 原文描述与正文识别

纯 Chrome 扩展，使用自己的 OpenAI 兼容 API Key 或知乎直答，将网页转为可编辑的知乎提问草稿。macOS、Windows、Linux 使用同一份 ZIP，无需本地服务或伴侣程序。

## 本次更新

- **切换问题描述形式**：在 Dashboard / 扩展弹窗选择「概括提问」或「网页原文」，自动记忆偏好，对下一次分析生效，已有草稿保持不变。
- **标题 + 原文**：模型只生成问题标题与话题，问题描述直接使用已加载正文，不经模型改写；保留标点、段落顺序和重复段落，段间无空行，引用链接附在末尾。
- **正文识别修复**：定位财新正文容器，排除站点附加的 AI 指令、菜单、推荐与隐藏内容，不再把整页外壳作为原文兜底。
- **部分正文也可使用**：页面只加载部分正文时仍可生成和填写，面板提示「已加载部分」；提示不混入问题描述，不读取隐藏内容或绕过订阅限制。
- **长文交接**：原文描述最多支持 20 万字符，超出明确提示，不静默截断。模型生成标题的输入仍有独立的精简预算。
- 保留流式草稿、多模型切换、自由拖动、网站过滤、真实话题匹配与发布后草稿清理。

## 下载与升级

下载附件 `ZhihuQuestionAssistant-Extension-2.1.7.zip` 并解压。**下载 ZIP 不会自动更新 Chrome 中已安装的版本。**

1. 替换原来加载的扩展目录，或在 `chrome://extensions` 开启开发者模式后加载新的解压目录（直接包含 `manifest.json`）。
2. 重新加载扩展，确认版本为 **2.1.7**。
3. 刷新已打开的网页，并重新分析。旧草稿不会自动替换。

无需先卸载，原本本机保存的配置可继续使用；仅会话保存的密钥可能需要重新填写。不需要旧版 macOS / Windows 伴侣程序。

## 验证与边界

- 68 项自动测试、语法检查和差异检查通过；正文定位和可见性过滤已做浏览器回归验证。
- 未调用付费模型或发布真实知乎问题。自动填写仍取决于知乎网页结构，最终发布由用户审核并点击。
- 只读取当前页面已加载的可见正文，不保证取得完整文章；原文转载需遵守来源网站的授权要求。
- OpenRouter Base URL 使用 `https://openrouter.ai/api/v1`，不要填写完整 `/chat/completions` 地址。
- 旧选区残留、多设置窗口并发保存覆盖仍是已知待修问题，详见 [CODE_REVIEW.md](https://github.com/BretDeng/zhihu-question-assistant/blob/main/CODE_REVIEW.md)。
