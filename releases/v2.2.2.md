# 知乎提问助手 v2.2.2 · 教程、面板和字数上限

纯 Chrome 扩展，使用自己的 OpenAI 兼容 API Key 或知乎直答，将网页转为可编辑的知乎提问草稿。macOS、Windows、Linux 使用同一份 ZIP，无需本地服务或伴侣程序。

## 本次更新

### 改进

- **新手教程改成一步一步**：一次只显示当前这一步，用「上一步 / 下一步」翻页。常见问题收在最后，需要时再打开。网页面板里的引导也改成一次只提示一步。
- **「问」和提问面板一起移动**：按住「问」或面板标题栏，两者保持相对位置一起拖动。空间不够时面板改到按钮另一侧，不会把按钮挤走。

### 修复

- **付费墙正文**：部分网站（如 Foreign Affairs）把可见正文放在 `paywall-content` 里。这个类名以前会被当成付费墙整段丢弃，于是提示「当前页面正文较少」。现在保留已经显示的正文，仍排除「Finish reading」一类的付费提示。页面只加载了开头时，原文模式会标明「已加载部分」。
- **知乎 3000 字上限**：问题描述和「引用来源」加在一起不超过 3000 字。提取原文时按段落截断并留出链接的位置。超出时问题卡片标明「含引用已截取至 3000 字」。

完整列表见 [CHANGELOG.md](https://github.com/BretDeng/zhihu-question-assistant/blob/main/CHANGELOG.md)。

## 下载与升级

下载附件 `ZhihuQuestionAssistant-Extension-2.2.2.zip` 并解压。**下载 ZIP 不会自动更新 Chrome 中已安装的版本。**

1. 替换原来加载的扩展目录，或在 `chrome://extensions` 开启开发者模式后加载新的解压目录（直接包含 `manifest.json`）。
2. 重新加载扩展，确认版本为 **2.2.2**。
3. 刷新已打开的网页。

无需先卸载，原本本机保存的配置可继续使用；仅会话保存的密钥可能需要重新填写。

## 验证与边界

- 76 项自动测试与语法检查通过。
- 未调用付费模型或发布真实知乎问题。自动填写仍取决于知乎网页结构，最终发布由用户审核并点击。
- 付费墙后面未加载的正文仍然无法提取，只能使用页面已经显示的部分。
