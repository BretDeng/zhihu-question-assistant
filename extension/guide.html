QUESTION LAB · 新手教程

五分钟上手知乎提问助手

在任意网页点右下角的「问」，助手会读取当前网页，生成 6 个不同角度的知乎问题草稿；你编辑满意后一键带到知乎，自动填写标题、描述和话题。插件不会替你发布，最后一步始终由你确认。

  1. 添加模型

    点击浏览器工具栏里的扩展图标（或上方「打开模型设置」），选择「添加配置」。两种提供方任选其一：

    知乎直答

    提供方选「知乎直答」，模型可选 zhida-agent（默认）、zhida-fast-1p5（更快）或 zhida-thinking-1p5（更深入）。密钥使用知乎数据开放平台的 Access Secret，获取步骤见下方。注册后有免费调用额度（官网标注每天 5000 次）。

    OpenAI 兼容 API

    填写服务商的 API 地址（通常以 /v1 结尾，如 https://api.openai.com/v1）、模型名称和 API Key。只要接口兼容 /chat/completions 即可使用。首次保存时浏览器会请求访问该域名，请点「允许」。

    获取知乎直答 Access Secret

    1. 打开 知乎数据开放平台，点右上角「注册」或「登录」，用知乎账号登录（手机验证码或知乎 App 扫码均可）。
    2. 登录后进入 个人中心，创建密钥并复制 Access Secret。
    3. 回到本扩展的设置面板，点「添加配置」，配置名称随意（如「知乎直答」），提供方选「知乎直答」。
    4. 选择模型档位，把 Access Secret 粘贴到「API Key / Access Secret」，勾选「记住密钥」，点「保存并使用」。

    Access Secret 相当于账号凭证，不要分享给他人；如果泄露，请在个人中心重新创建。

    勾选「在这台设备上记住密钥」后，密钥保存在本机扩展存储（不同步云端）；不勾选则浏览器关闭后需要重新填写。可保存多套配置，随时一键切换。

  2. 选择问题描述形式

    在设置面板的「问题描述形式」中选择：

    • 概括提问：模型根据网页内容写一段精简的背景和讨论点，适合大多数情况。
    • 网页原文：问题描述直接使用网页已加载的正文，模型只生成标题和话题，原文不会被改写。

  3. 在网页上生成草稿

    • 打开一篇文章或新闻，点击右下角的「问」打开面板。
    • 想聚焦某一段？先选中这段文字，助手会优先围绕选中内容提问。
    • 点「分析当前网页」，6 个草稿会边生成边出现，先出来的可以先编辑。
    • 标题、描述和话题建议都可以直接修改，话题之间用顿号或逗号分隔。

  4. 去知乎提问

    • 在满意的草稿上点「去知乎提问」，助手会在新标签页打开知乎（需要已登录）。
    • 知乎页面右下角会出现「提问草稿」面板，并自动打开提问框，填写标题、描述和引用来源链接。
    • 随后通过知乎的 # 话题按钮搜索话题，只绑定名称完全一致的已有话题，其余会列出供你手动确认。
    • 检查无误后，由你自己点击发布。已有内容不会被覆盖，自动填写失败时可用「复制」按钮手动粘贴。

  5. 小技巧

    • 「问」按钮和面板标题栏都可以拖动，挡住内容时挪开即可，「问」的位置会被记住；按 Esc 可收起面板。
    • 不想在某些网站看到「问」？在设置面板的「网站过滤」中加入域名，已打开的页面会立即生效。
    • 面板底部会显示首个草稿和总耗时，便于比较不同模型的速度。
